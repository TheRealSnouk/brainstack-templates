# Global (personal) brain files

Facts about *you* (your OS, shell, experience level, how you like answers) belong in a user-level file
that applies to every project. Facts about the *project* belong in the repo.

| Tool | Global file |
|---|---|
| Claude Code | `~/.claude/CLAUDE.md` |
| Gemini CLI and Antigravity | `~/.gemini/GEMINI.md` |
| Cursor | Settings > Rules (User Rules) |
| GitHub Copilot | Personal custom instructions in Copilot settings |

On Windows, `~` is `C:\Users\<you>`. Copy [about-me.md](about-me.md) into the right place and edit it.
